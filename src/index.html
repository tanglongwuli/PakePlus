关于

唐长老超级物理白板

面向讲台教学的轻量白板工具，所有图形来自同目录的 shapes.js 图形库，可自行扩展。

支持多页、自由绘制、图形拖拽 / 缩放 / 旋转，以及边框、填充、线条样式的细致调节； 动画图形可独立或全局播放，并可导出为 PNG 图片或 WebM 视频； 选中多个图形后还能一键组合为新图形并写回 shapes.js。 菜单里还可进入图形库管理管理图形的显示与删除，以及打开小程序浮窗 （本地时间、倒计时、秒表、点名器、随机数、骰子）。

内置图形分类：基础、力学、振动与波、光学、电磁、文字、简笔画、动画、近代物理等。 可在 shapes.js 中继续追加新的 shape({...}) 定义，保存刷新页面即可生效。

帮助

基本操作

· 打开程序默认处于画笔状态，可直接书写；点击「选择」切换为选择模式。

· 底部工具栏：选择、画笔、橡皮、形状、撤销、重做、动画播放 / 暂停 / 重置。

· 点击「画笔」直接进入绘画，再次点击「画笔」才打开颜色 / 粗细 / 线型面板。

· 橡皮为像素擦除：擦掉图形的一部分，移动 / 缩放后擦痕仍保留；触摸屏用力越大、接触面积越大，擦除范围越大；鼠标滚轮可调大小。

· 双击「橡皮」显示滑动条，向右滑动到底清除本页所有图形；清空后会自动切回画笔。

· 点「形状」可切换类别并挑选图形，绘制完自动切回「选择」工具，需再点一次图形才会选中。

选择与调整

· 选中图形后，图形下方出现标签：播放 / 重置 / 边框 / 填充 / 参数 / 置顶 / 克隆 / 组合 / 删除。

· 拖动图形可移动；拖动控制点可缩放；拖动上方旋转柄可旋转；拖动顶点可改变线段 / 折线形状。

· 框选或按住 Ctrl / Shift 可多选；Ctrl+A 全选。

· 克隆：先选中一个或多个图形，点「克隆」开启克隆模式，再拖动其中任意一个被选中的图形，整个选区会一起复制并跟着手指 / 鼠标拖动；原图形留在原地不动。

· 置顶：把选中图形移到当前页最上层。

文字

· 选中「文字」工具后在画布点击，会弹出文字输入框，直接输入即可；双击已有文字可重新编辑内容与样式。

· 文字支持字体、字号、加粗、斜体、下划线、对齐方式与颜色；这些属性也可在 shapes.js 的文字图形定义里预设默认值。

· 文字也支持边框 / 填充，填充颜色和不透明度可在标签栏里调整。

动画

· 带有 animatable 的图形（动画分类、部分力学 / 电磁图形）支持动画。

· 选中动画图形后，标签栏会出现「播放 / 暂停」和「重置」；也可用底部工具栏全局播放 / 暂停 / 重置。

· 空格 播放 / 暂停全部动画，R 让全部动画时间归零。

· 「参数」面板里可调动画周期、振幅、角度、质量比等图形参数。

组合与图形库

· 组合：框选或按住 Ctrl / Shift 多选两个以上图形后，点「组合」（或按 Ctrl+G）即可把它们打包成一个新图形，可命名、生成图标、选择类别，并写入 shapes.js 保存。

· 保存方式：写入 shapes.js / 生成新的 shapes.js 并下载 / 仅本次会话使用。

· 图形库管理：菜单 →「图形库管理」（或 Ctrl+L）。可用类别下拉栏筛选图形，只有自定义（组合）图形能被勾选删除；内置 / 动画图形无法删除，但可以点右侧的眼睛按钮隐藏——隐藏状态会被永久记住（保存在浏览器本地），刷新后依然保持隐藏，再点一次即可恢复显示。

· 画布上正在使用被删除图形的对象会一并清理，可用 Ctrl+Z 撤销。

小程序

· 菜单 →「小程序」，可打开本地时间、倒计时、秒表、点名器、随机数、骰子等浮窗。

· 浮窗可拖动、可关闭；点击标题栏右侧的放大按钮可循环切换 1× / 2× / 4× 三档大小。

· 时间类小程序（本地时间、倒计时、秒表）停止操作几秒后会自动进入沉浸模式，卡片轮廓、标题栏与按钮会平滑淡出，只保留时间大字；点一下时间或鼠标移上去即可恢复。

· 点名器名单会保存在浏览器本地。

吸附

· 拖动 / 缩放 / 拉顶点时自动吸附其它图形的特殊点（角、边中点、中心、顶点）。

· 可在设置里开启 / 关闭吸附、调节吸附半径；按住 Alt 可临时关闭本次吸附。

页面与缩略图

· 右下角点击页码，可查看所有页缩略图并跳转。

· 可上一页 / 下一页 / 新建页。

· 图形列表和缩略图列表支持手指上下滑动浏览。

导出

· 菜单 →「导出图片」：可导出当前页、全部页码或指定页码范围，保存为 PNG。

· 菜单 →「导出动画视频」：可把动画图形录制成 WebM 视频，支持当前页 / 全部页面、时长、帧率、清晰度设置。

· 设置里可指定导出文件夹，下次打开仍会记住；若不设置则使用浏览器默认下载位置。

· 导出视频需要浏览器支持 MediaRecorder（Chrome / Edge 均可）；录制耗时约等于设定时长，期间请勿操作画布或切换页面。

设置与快捷键

· 设置里可切换画布背景、开启 / 关闭吸附并调半径、指定导出保存位置。
